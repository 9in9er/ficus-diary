# Очистка старых base64 завершена

Миграция фотографий в Yandex Object Storage и удаление старых base64 из production
завершены. Одноразовые инструменты переноса и очистки, их npm-команды и серверные
тесты удалены. История реализации сохранена в Git; повторная очистка не требуется.

Для проверки целостности сохранены [verifier](../scripts/verify-photo-migration.cjs)
и команда `verify:photos`. Порядок запуска описан в
[текущей инструкции](object-storage.md#7-проверка-целостности-фотографий).
Инструменты [резервного копирования](firestore-backup.md) сохранены.

Клиентский fallback на старое `photo` удалён. Тесты отображения и предпросмотра по
`photoKey`, растений без фотографии и отсутствия записи старого поля сохранены.
Переходные Rules и исторические тесты перехода удалены; действующие ограничения
проверяет основной [набор тестов Rules](../tests/firestore/plants.rules.test.cjs).
