Hey!

This app is for you and your plants. You can:

* add photo
* add watering
* add another notes
* sorted your plants and never don't forget watering

[Try it!](https://ficus-diary.ru/)

Фотографии хранятся в приватном Yandex Object Storage, а ключи объектов — в Firestore.
Настройка, локальная разработка и постоянное удаление растений из корзины:
[docs/object-storage.md](docs/object-storage.md).

Образец переменных окружения: [.env.example](.env.example).

История первого выпуска Object Storage и переходных Firestore Rules:
[docs/production-release.md](docs/production-release.md). Текущая инструкция —
[docs/object-storage.md](docs/object-storage.md).
